# Enhanced Survival / Улучшенное Выживание

Аддон для Minecraft Bedrock Edition 1.21+

## Описание

Этот аддон делает выживание более сложным и интересным, изменяя поведение существующих мобов и механики добычи ресурсов.

## Изменения

### Мобы

| Моб | Изменения |
|-----|-----------|
| **Зомби** | Больше здоровья (25 HP), больше урона (5), чуют игрока на расстоянии 35 блоков, ломают двери |
| **Паук** | Теперь ядовит! Отравление на 8 секунд при укусе, более агрессивный |
| **Скелет** | Больше здоровья (24 HP), стреляет быстрее и точнее, видит на 25 блоков |
| **Крипер** | Больше здоровья (25 HP), сопротивление отбрасыванию, обнаруживает игрока на 20 блоков |
| **Волк (прирученный)** | Больше здоровья (30 HP), больше урона (8) - отличный защитник! |

### Ресурсы

| Руда | Изменения |
|------|-----------|
| **Алмазная руда** | 30% шанс не выпасть |
| **Железная руда** | 25% шанс не выпасть |
| **Золотая руда** | 25% шанс не выпасть |

## Установка

### Способ 1: Автоматический
1. Скачайте `.mcaddon` файл
2. Дважды кликните по нему
3. Minecraft автоматически импортирует аддон

### Способ 2: Ручной
1. Скачайте оба пака (BP и RP)
2. Скопируйте `EnhancedSurvival_BP` в:
   - **Windows**: `%localappdata%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\behavior_packs`
   - **Android**: `games/com.mojang/behavior_packs`
   - **iOS**: `Minecraft/games/com.mojang/behavior_packs`
3. Скопируйте `EnhancedSurvival_RP` в соответствующую папку `resource_packs`
4. Активируйте оба пака в настройках мира

## Совместимость

- Minecraft Bedrock Edition 1.21.0+
- Windows 10/11, Android, iOS, Xbox, PlayStation, Nintendo Switch

## Советы по выживанию

- Носите с собой молоко для снятия яда от пауков
- Стройте крепкие двери или используйте железные - зомби ломают деревянные!
- Используйте собственность Fortune на кирке для компенсации уменьшенного дропа
- Приручите волков - они станут мощными защитниками!

# English

## Description

This addon makes survival more challenging by modifying existing mob behavior and resource gathering mechanics.

## Changes

### Mobs
- **Zombie**: More health (25 HP), more damage (5), detects players from 35 blocks, breaks doors
- **Spider**: Now poisonous! 8 seconds poison on bite, more aggressive
- **Skeleton**: More health (24 HP), shoots faster and more accurately, sees 25 blocks
- **Creeper**: More health (25 HP), knockback resistance, detects players from 20 blocks
- **Tamed Wolf**: More health (30 HP), more damage (8) - great defender!

### Resources
- **Diamond ore**: 30% chance to drop nothing
- **Iron ore**: 25% chance to drop nothing
- **Gold ore**: 25% chance to drop nothing

## Compatibility

- Minecraft Bedrock Edition 1.21.0+
- Windows 10/11, Android, iOS, Xbox, PlayStation, Nintendo Switch
